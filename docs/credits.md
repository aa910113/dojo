# 第三方素材與授權

## KanjiVG(手寫辨識的筆順資料)

`data/kana-strokes.json` 由 [KanjiVG](https://kanjivg.tagaini.net/) 的假名筆畫資料衍生而來:
取出每個假名的筆畫路徑,重新取樣成固定點數並正規化座標,供手寫測驗比對筆跡使用。
